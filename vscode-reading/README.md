# VS Code 阅读采集

此本地扩展配合学习面板使用。启动 VS Code 后自动连接本机学习服务，不增加采集按钮；只有在面板开始采集、选中 VS Code 窗口并切回该窗口时才发送文字。

采集当前活动文本编辑器的可见行，保留空白、缩进、符号、大小写和行号。折叠部分、未打开文件、资源管理器、终端、聊天和其他面板不采集。不执行代码、不修改文件或 VS Code 设置，也不把整个项目扫描入库。横向滚动隐藏的内容仍属于可见行，会一并读取；Markdown 预览、Notebook、图片等不是文本编辑器，当前不支持。

一轮锁定一个窗口、一个文件及其内容版本。切到其他窗口或文件时暂停；文件修改后请结束该轮再重新开始。已保存材料接入原来的提要、出题、判卷与知识导航。

文字通过随机配对密钥发送至本机 127.0.0.1:7788/7789；密钥由本机学习服务写入 `%APPDATA%/study-system/vscode-reading-端口.json`。扩展不连接云端，后续出题等步骤仍会把采集文字交给学习面板中已选的 AI 模型。
